Student Financial Administration
Enrolment Status Mgt

This flow sends the financial clearance status (e.g., fees paid, outstanding balance) for each student from Student Financial Administration to Enrolment Status Management. Enrolment Status Management uses this to determine whether a student can be enrolled or re-enrolled; without it, students with unpaid fees could be incorrectly granted enrolment, leading to financial loss.
