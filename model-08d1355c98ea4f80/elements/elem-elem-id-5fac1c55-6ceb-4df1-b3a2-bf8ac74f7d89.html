Identity & Access Mgt
End User Computing

This flow delivers verified authentication credentials, including single sign-on tokens and multi-factor authentication configurations, from Identity and Access Management to End User Computing. End User Computing uses these credentials to provision user profiles on devices and enable secure logon; without them, users would be unable to access institutional systems from their assigned devices.
