High Performance Computing

This flow provides planned timelines for server, storage, and network hardware replacements from Infrastructure Lifecycle Management to High Performance Computing. High Performance Computing uses these schedules to coordinate research job submissions, plan maintenance windows, and migrate workloads; without them, HPC operations would be disrupted by unexpected hardware decommissioning, causing data loss or job failures.
