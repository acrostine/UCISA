Infrastructure Lifecycle Mgt
End User Computing

This flow carries updated network settings, including VLAN assignments, Wi-Fi credentials, and proxy configurations, from Infrastructure Lifecycle Management to End User Computing. End User Computing uses these updates to configure device network profiles and ensure connectivity; without them, devices would lose network access or connect to insecure segments, disrupting user productivity.
