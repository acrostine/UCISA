Curriculum Performance Mgt ()
## Purpose This process ensures that curriculum performance is continuously monitored and evaluated using quantitative and qualitative data. It provides a structured mechanism for generating evidence-based insights, producing performance reports, and driving targeted improvements to teaching quality and student learning outcomes. ## Roles - **Data Analyst**: Collects and prepares performance data from various sources. - **Curriculum Manager**: Oversees the analysis and report generation. - **System**: Automates data aggregation and report compilation. - **Curriculum Committee**: Reviews the performance report, approves recommendations, or identifies issues. - **Instructional Designer**: Implements approved curriculum changes. ## Upstream Inputs - Student Assessment Results - Retention Rate Data - Student Feedback Surveys - Instructor Feedback - Historical Curriculum Performance Data ## Downstream Outputs - Curriculum Performance Report - Approved Recommendations for Improvement - Implemented Curriculum Changes - Final Review Confirmation ## Key Decisions - Whether the performance report meets quality standards and contains valid findings. - Whether recommendations are approved for implementation or require remediation. - Whether implemented changes have achieved the desired improvement. ## Exception Paths - If the performance report contains errors or insufficient analysis, it is sent back for rework. - If the curriculum committee identifies issues with the recommendations, a remediation step is triggered before re-review. - If implemented changes fail to meet objectives, the process may loop back to the analysis phase. ## Step Walkthrough 1. **Collect Performance Data**: The Data Analyst gathers student assessment results, retention rates, and feedback from multiple systems and sources. 2. **Analyse Curriculum Data**: The Curriculum Manager reviews the collected data to identify trends, gaps, and areas needing improvement. 3. **Generate Performance Report**: The System compiles the analysis into a structured performance report with visualisations and key findings. 4. **Review Report and Recommendations**: The Curriculum Committee examines the report and evaluates the proposed recommendations for feasibility and impact. 5. **Approve or Identify Issues**: The committee decides whether to approve the recommendations or flag issues for remediation. 6. **Implement Approved Changes**: The Instructional Designer executes the approved curriculum modifications. 7. **Conduct Final Review**: The Curriculum Manager verifies that changes have been implemented correctly and that performance objectives are being met. Steps: 1. Collect Performance Data: The Data Analyst retrieves student assessment scores from the learning management system, retention statistics from the student information system, and feedback from survey platforms. All data is consolidated into a single dataset for analysis. 2. Analyse Curriculum Data: The Curriculum Manager applies statistical analysis and trend identification techniques to the dataset. They compare current performance against benchmarks and historical data to pinpoint areas of strength and weakness in the curriculum. 3. Generate Performance Report: The system generates a comprehensive performance report that includes data visualisations, trend summaries, gap analysis, and draft recommendations for improvement. The report is formatted for review by the curriculum committee. 4. Review Report and Recommendations: The Curriculum Committee meets to review the generated report. Members assess the validity of the findings, the clarity of the data presentation, and the practicality of the draft recommendations. They prepare to either approve or request changes. 5. Approve or Identify Issues: The committee votes on the report. If the findings are sound and recommendations are actionable, they approve the report. If errors, omissions, or impractical suggestions are found, they flag the issues for remediation. 6. Rework Report and Analysis: The Data Analyst and Curriculum Manager collaborate to correct errors, fill data gaps, or refine recommendations based on committee feedback. The reworked report is then resubmitted for review. 7. Implement Approved Changes: The Instructional Designer updates course materials, assessment rubrics, or teaching methods as per the approved recommendations. Changes are documented and communicated to relevant instructors. 8. Conduct Final Review: The Curriculum Manager checks that all approved changes have been applied correctly. They review initial post-implementation data to confirm improvements are on track and close the process.
