Academic Advice Mgt ()
## Purpose This process enables the institution to deliver structured, personalised academic advice to students. It ensures that course selection, progression checks, and academic requirement reviews are handled consistently, with clear documentation and escalation paths for complex cases. ## Roles - Student (initiates request) - Academic Advisor (reviews records, assesses request, provides advice) - System (automates plan generation and notifications) - Student Support Manager (escalation point for complex cases) ## Upstream Inputs - Student Academic Records (grades, enrolment status, progression history) - Curriculum Information (course catalogues, prerequisite rules, degree requirements) - Student Advice Request (submitted via portal or in person) ## Downstream Outputs - Personalised Academic Plan (documented course plan and progression pathway) - Support Intervention Record (logged actions for at-risk students) - Advice Confirmation Notification (sent to student) ## Key Decisions - Whether the student's request meets standard progression criteria - Whether a support intervention is required (e.g., academic risk, prerequisite gaps) - Whether the case requires escalation to a Student Support Manager ## Exception Paths - If progression criteria are not met, a support intervention is initiated before a plan is generated - If the advisor cannot resolve the case, it is escalated to the Student Support Manager - If the student disagrees with the plan, a rework loop allows the advisor to reassess ## Step Walkthrough 1. Receive Advice Request: The student submits an academic advice request via the portal or in person, which is logged in the system. 2. Review Student Records: The Academic Advisor retrieves and reviews the student's academic records and curriculum information to understand the context. 3. Assess Request Against Criteria: The advisor evaluates the request against progression rules and academic requirements, determining if it is straightforward or requires intervention. 4. Initiate Support Intervention: If criteria are not met, the advisor logs a support intervention record and notifies the Student Support Manager for follow-up. 5. Generate Academic Plan: If criteria are met, the system generates a personalised academic plan based on the student's records and curriculum data. 6. Review Plan with Student: The advisor reviews the generated plan with the student, explaining course selections and progression steps. 7. Confirm and Communicate Plan: The student confirms acceptance of the plan, and the system sends a confirmation notification with the finalised plan. Steps: 1. Receive Advice Request: The process begins when a student initiates an academic advice request. This can be done through the student portal or during a face-to-face meeting. The request is logged in the academic advice system with a timestamp and student identifier. 2. Review Student Records: The Academic Advisor accesses the student's academic history, current enrolment, and curriculum requirements. This step ensures the advisor has full context before assessing the request. The system displays relevant data in a consolidated view. 3. Assess Request Against Criteria: The advisor checks whether the student's request meets standard progression criteria, prerequisite requirements, and degree rules. This is a decision point that determines the next action. The system provides a checklist of criteria for consistency. 4. Initiate Support Intervention: When the assessment reveals issues such as academic risk, prerequisite gaps, or progression blocks, the advisor initiates a support intervention. This is logged in the system and flagged for the Student Support Manager. The intervention may include tutoring referrals, study skills workshops, or academic coaching. 5. Generate Academic Plan: For students who meet the criteria, the system automatically generates a personalised academic plan. The plan includes recommended courses, a progression timeline, and notes on degree requirements. The advisor can review and adjust the plan before presenting it to the student. 6. Review Plan with Student: The advisor presents the personalised academic plan to the student, explaining each recommended course and the rationale. The student can ask questions and request adjustments. If the student disagrees, the advisor can rework the plan. 7. Confirm and Communicate Plan: Once the student confirms acceptance of the academic plan, the system finalises the record and sends a confirmation notification to the student. The plan is stored in the student's academic profile for future reference.
