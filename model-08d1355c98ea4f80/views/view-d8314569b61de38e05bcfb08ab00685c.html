Information Analytics ()
## Purpose This process transforms institutional data into actionable insights through statistical analysis, modelling, and visualisation techniques. It consumes clean and structured datasets and produces analytic reports and predictive models. These outputs enable evidence-based decision-making that improves student outcomes, operational efficiency, and strategic initiatives. ## Roles - Data Analyst: Performs statistical analysis, modelling, and visualisation - Lead Analyst: Reviews and validates analytical outputs - System: Automated data processing and model generation ## Upstream Inputs - Clean Structured Dataset: The primary input for analysis - Analysis Request: Defines scope, questions, and success criteria ## Downstream Outputs - Analytic Report: Final report with findings and visualisations - Predictive Model: Validated model for forecasting - Insights Package: Consolidated outputs for decision-makers ## Key Decisions - Is the analysis scope clear and feasible? - Do the results meet quality and accuracy thresholds? - Are the insights actionable and ready for dissemination? ## Exception Paths - If the analysis request is unclear, it is returned to the requester for clarification. - If validation fails, the analysis is reworked and re-validated. - If results are not actionable, additional refinement is performed before finalisation. ## Step Walkthrough 1. Receive Analysis Request: The Data Analyst receives the analysis request, which includes the business question, scope, and required outputs. They confirm the request is clear and complete, and that the necessary clean dataset is available. If the request is unclear, it is returned to the requester for clarification. 2. Scope Analysis: The Data Analyst defines the scope of the analysis, including the statistical methods, modelling techniques, visualisation types, and success criteria. This step ensures alignment with the business question and data availability. The output is a brief analysis plan. 3. Perform Statistical Analysis: The Data Analyst applies descriptive and inferential statistical methods to the clean structured dataset. This includes calculating metrics, identifying trends, and generating initial findings. The output is a set of statistical results and preliminary visualisations. 4. Develop Predictive Model: The Data Analyst selects an appropriate modelling technique (e.g., regression, classification, time series) and trains the model on the clean dataset. The model is evaluated for accuracy and performance. The output is a draft predictive model with performance metrics. 5. Validate Results: The Lead Analyst reviews the statistical results and draft predictive model against the success criteria defined in the analysis plan. They assess accuracy, relevance, and actionability. If the results meet thresholds, they are approved; otherwise, they are returned for rework. 6. Rework Analysis: The Data Analyst reworks the statistical analysis or predictive model based on feedback from the Lead Analyst. This may involve refining methods, correcting errors, or improving model performance. The updated outputs are sent back for re-validation. 7. Package Insights: The Data Analyst consolidates the validated statistical results, predictive model, and visualisations into a comprehensive analytic report. They also prepare model documentation for deployment. The output is a final insights package ready for dissemination. 8. Deliver Insights Package: The Data Analyst delivers the final analytic report and predictive model to the requesting stakeholders. The outputs are archived in the analytics repository for future reference. The process concludes with a notification to all relevant parties.
