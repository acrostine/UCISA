Receive Access Request: The system receives an access request from a library patron, including user identification and the specific resource (physical or digital) being requested. This step initiates the process and logs the request for tracking. 2. Validate Membership: The system automatically validates the user's membership against the membership database. It checks for active status, expiration date, and any membership restrictions. If invalid, the process branches to rejection. 3. Check Resource Availability: The system queries the library inventory system to check the availability of the requested resource. For physical items, it checks if copies are on shelf; for digital items, it checks license availability. If unavailable, the process branches to offer alternatives. 4. Review User Obligations: The system checks the user's account for any outstanding obligations such as overdue items, unpaid fines, or borrowing limits. If obligations exist, the request is flagged for remediation before proceeding. 5. Authorize Access: Library staff reviews the validated request, including membership status, resource availability, and obligations check. They apply library policies to approve or deny the access. This is a manual decision step. 6. Record Usage Transaction: The system records the transaction in the library management system, linking the user to the resource. This includes borrowing date, due date (for physical items), or access period (for digital items). 7. Notify Patron: The system sends a notification to the patron via email or portal message. For approved requests, it includes access instructions or pickup details. For denied requests, it includes the reason and any next steps. 8. Resolve Membership Issues: Library staff contacts the patron to resolve membership issues, such as renewal or reactivation. Once resolved, the request can be re-evaluated. 9. Resolve Obligations: Library staff works with the patron to clear outstanding obligations, such as returning overdue items or paying fines. Once resolved, the request proceeds to authorization.
