## Purpose Programme Enrolment manages the end-to-end registration of students onto academic programmes. It processes incoming application data, verifies applicant eligibility against programme entry criteria, and produces admission decisions. The process ensures that only qualified applicants are enrolled and that validated enrolment records are created for use by student information systems, academic planning, and regulatory reporting. ## Roles - Enrolment Officer: Reviews application data and verifies eligibility - Admissions Manager: Makes final admission decisions and approves exceptions - System: Automates eligibility checks and records enrolment data ## Upstream Inputs - Student Application Data - Programme Entry Requirements - Supporting Documentation (transcripts, certificates) ## Downstream Outputs - Validated Enrolment Record - Admission Decision Notification - Rejection Notification ## Key Decisions - Does the applicant meet all programme entry requirements? - Should an exception be granted for borderline cases? - Is the enrolment record complete and accurate? ## Exception Paths - If eligibility check fails, the application is rejected and the applicant is notified. - If the applicant is borderline, the case is escalated to the Admissions Manager for a decision. - If enrolment data is incomplete, the record is flagged for correction before finalisation. ## Step Walkthrough 1. Receive Application: The Enrolment Officer receives the student's application form, academic transcripts, certificates, and any other required supporting documents. The application is logged into the tracking system with a unique identifier. All incoming data is checked for basic completeness before proceeding. 2. Review Application Data: The Enrolment Officer examines the application data to ensure all required fields are populated and that supporting documents are present and legible. Any discrepancies or missing information are noted. The officer confirms the application is ready for eligibility verification. 3. Verify Eligibility: The system runs an automated eligibility check comparing the applicant's qualifications, grades, and documentation against the predefined entry requirements for the chosen programme. The check produces a pass/fail result and highlights any borderline conditions. 4. Assess Eligibility Results: The Enrolment Officer reviews the eligibility check result. If the applicant clearly meets all criteria, the process moves to enrolment recording. If the applicant clearly fails, the process moves to rejection. If the result is borderline or requires human judgment, the case is escalated. 5. Escalate Borderline Case: When the eligibility check produces a borderline result or the officer identifies a need for exception handling, the case is escalated to the Admissions Manager. The escalation includes the application data, eligibility results, and a summary of the issue requiring decision. 6. Make Admission Decision: The Admissions Manager reviews the escalated case file, considers the eligibility results and any exceptional circumstances, and makes a final admission decision. The decision is either to approve the enrolment or to reject the application. The decision is recorded in the system. 7. Record Enrolment: Upon approval, the system creates a new enrolment record in the student information system. The record includes the student's personal details, programme of study, start date, and any conditions or notes from the admission decision. The record is marked as pending validation. 8. Validate Enrolment Record: The Enrolment Officer reviews the newly created enrolment record to ensure all data is correct and complete. Any errors or missing fields are corrected. Once validated, the record is marked as final and ready for downstream use. 9. Notify Applicant: The system generates and sends a notification to the applicant with the admission decision. For approved applicants, the notification includes enrolment details and next steps. For rejected applicants, the notification includes the reason for rejection and any appeal information.
