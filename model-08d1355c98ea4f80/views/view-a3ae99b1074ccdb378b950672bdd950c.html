Space Utilisation ()
## Purpose Space Utilisation ensures that campus facilities are allocated and occupied in the most efficient manner possible, supporting academic and administrative functions while maximising the value of physical resources. The process uses real-time occupancy data, scheduling inputs, and strategic directives to drive allocation decisions and produce actionable utilisation reports. ## Roles - Facilities Manager: Oversees the process, reviews reports, and approves allocation changes. - Space Analyst: Collects and analyses occupancy data, identifies utilisation trends. - Scheduling Coordinator: Provides current and planned scheduling requirements. - System: Automates data collection, analysis, and report generation. ## Upstream Inputs - Occupancy Data Feed: Real-time and historical occupancy data from sensors and manual surveys. - Scheduling Requirements: Current and planned room bookings and usage schedules. - Strategic Plan: Campus development and space optimisation goals. ## Downstream Outputs - Space Utilisation Report: Comprehensive report detailing occupancy rates, trends, and recommendations. - Allocation Decision Record: Documented decisions on space reallocation or reassignment. - Updated Space Inventory: Revised inventory reflecting allocation changes. ## Key Decisions - Whether a space is underutilised and requires reallocation. - Whether occupancy data is sufficient for analysis or requires remediation. - Whether scheduling conflicts necessitate escalation. ## Exception Paths - Data Quality Issue: If occupancy data is incomplete or erroneous, a remediation step is triggered to correct the data feed. - Scheduling Conflict: If allocation recommendations conflict with existing bookings, the conflict is escalated for resolution. - Strategic Misalignment: If proposed allocation does not align with strategic plans, it is flagged for review. ## Step Walkthrough 1. Collect Occupancy Data: The system automatically collects real-time and historical occupancy data from IoT sensors installed in campus facilities, supplemented by manual survey inputs from facilities staff. This raw data forms the foundation for all subsequent analysis and is stored in the central data repository. 2. Validate Data Quality: The Space Analyst examines the collected data for gaps, anomalies, or errors such as sensor failures or missing manual entries. If the data passes quality checks, it proceeds to analysis. If issues are found, the data is flagged for remediation before further processing. 3. Remediate Data Issues: When data quality issues are identified, the Space Analyst investigates the root cause, corrects errors, or supplements missing data through manual surveys or sensor recalibration. The remediated data is then re-submitted for validation. 4. Analyse Utilisation Trends: Using the validated occupancy data, the Space Analyst performs trend analysis to identify utilisation rates, peak usage times, and underutilised or overburdened spaces. This analysis produces a utilisation trends report that highlights opportunities for optimisation. 5. Review Scheduling Requirements: The Scheduling Coordinator extracts current room bookings and planned scheduling requirements from the scheduling system. This data is cross-referenced with utilisation trends to identify conflicts or opportunities for reallocation. 6. Assess Allocation Needs: The Facilities Manager reviews the utilisation trends report alongside current and planned booking data to identify spaces that are underutilised or overburdened. This assessment determines whether reallocation is necessary and proposes specific changes to space assignments. 7. Approve Allocation Change: The Facilities Manager reviews the allocation proposal for alignment with strategic plans and operational needs. If approved, the change is enacted. If rejected, the proposal is sent back for rework with feedback. 8. Rework Allocation Proposal: The Space Analyst incorporates feedback from the Facilities Manager to revise the allocation proposal, addressing any concerns about strategic alignment or operational feasibility. The revised proposal is then resubmitted for approval. 9. Generate Utilisation Report: The system aggregates all analysis results, allocation decisions, and occupancy data into a standardised utilisation report. This report includes occupancy rates, trend graphs, and recommendations for future space management. 10. Update Space Inventory: The system records the approved allocation changes in the central space inventory database, ensuring that all records reflect current assignments. This updated inventory is used for future scheduling and reporting.
