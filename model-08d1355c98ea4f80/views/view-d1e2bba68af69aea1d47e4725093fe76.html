## Purpose Research Output Management ensures that all scholarly products from the institution are properly catalogued, legally compliant, openly accessible where required, and tracked for impact. This process supports academic reputation, reporting obligations, and long-term preservation. ## Roles - **Researcher**: Submits output and remediates copyright or access issues - **Research Support Officer**: Registers outputs, assesses compliance, and publishes to repository - **Repository System**: Automates metadata capture and impact metric retrieval ## Upstream Inputs - Research findings and publication materials - Funder open access policies - Copyright and licensing agreements - Researcher submission notification ## Downstream Outputs - Verified repository record with metadata - Open access compliant output (where applicable) - Impact metrics report - Archived publication file ## Key Decisions - Is the output copyright-compliant for repository deposit? - Does the output require open access under funder mandate? - Are impact metrics available and captured? ## Exception Paths - Copyright issues found: output is returned to researcher for rights clearance - Open access embargo required: output is deposited with embargo date and metadata only - Impact metric retrieval fails: manual entry is triggered ## Step Walkthrough 1. **Submit Research Output**: Researcher submits the publication, presentation, or patent file along with metadata to the Research Support Office. 2. **Register Output Record**: Research Support Officer creates a preliminary record in the institutional repository system with basic metadata. 3. **Assess Copyright Compliance**: Research Support Officer reviews copyright agreements and publisher policies to determine if the output can be deposited. 4. **Review Open Access Status**: Research Support Officer checks funder mandates and journal policies to determine open access requirements and any embargo period. 5. **Resolve Compliance Issues**: Researcher addresses any copyright or open access gaps identified, such as securing permissions or applying a licence. 6. **Publish to Repository**: Research Support Officer uploads the final file, applies the appropriate access level (open, embargoed, or restricted), and finalises the record. 7. **Capture Impact Metrics**: Repository system automatically retrieves citation counts, altmetrics, and download statistics for the published output. Steps: 1. Submit Research Output: The researcher provides the final version of the publication, presentation, or patent document along with required metadata such as title, authors, abstract, and funding information. This initiates the output management workflow. 2. Register Output Record: The officer enters the submitted metadata into the institutional repository, assigns a temporary identifier, and attaches the file. The record is flagged as pending compliance review. 3. Assess Copyright Compliance: The officer checks the publisher's copyright policy, any author agreement, and funder requirements. They determine whether the submitted version can be deposited and under what conditions. 4. Review Open Access Status: The officer determines if the output is subject to an open access mandate, identifies any required embargo period, and checks if an APC has been paid or a licence is needed. 5. Resolve Compliance Issues: If copyright clearance is needed, the researcher obtains permission from the publisher. If an open access licence is required, they apply a Creative Commons licence. If an embargo applies, they note the embargo end date. 6. Publish to Repository: The officer uploads the approved file, sets the access level (open, embargoed, or restricted), applies metadata tags, and publishes the record. The output becomes discoverable. 7. Capture Impact Metrics: The system automatically queries external APIs for citation counts, social media mentions, news coverage, and download statistics. Metrics are attached to the repository record for reporting.
