Academic Skills Development ()
## Purpose This process ensures that students receive timely, data-driven support to develop essential academic skills in research, writing, and study techniques. It closes the loop between performance data and targeted intervention, continuously improving student outcomes and autonomy. ## Roles - Academic Skills Coordinator - Workshop Facilitator - System ## Upstream Inputs - Student Performance Data - Learning Outcome Feedback ## Downstream Outputs - Enhanced Student Competencies - Student Confidence Report - Updated Workshop Materials ## Key Decisions - Whether identified skill gaps warrant a new workshop or revision of existing resources - Whether student competency after the workshop meets the defined threshold ## Exception Paths - If competency assessment reveals gaps, the student is directed to a remediation step (rework deliverable) and then re-assessed - If performance data is insufficient, the process may pause for data collection ## Step Walkthrough 1. Deliver Workshop: The Workshop Facilitator conducts the session, providing instruction and materials to students. 5. Assess Competency: The system administers a post-workshop assessment to measure student competency gains. 6. Evaluate Effectiveness: The Academic Skills Coordinator reviews assessment results against the success threshold; if criteria are met, the process proceeds to closure; if gaps remain, it triggers remediation. 7. Rework Deliverable: The Academic Skills Coordinator revises the workshop materials or provides additional resources to address remaining gaps, then loops back to the delivery step. 8. Collect Performance Data: The system pulls recent student grades, assignment scores, and learning outcome reports from the institutional data warehouse. This data provides the baseline for identifying skill gaps. 2. Identify Skill Gaps: The Academic Skills Coordinator reviews the aggregated data, comparing student performance against expected benchmarks. They identify areas such as poor research methodology, weak writing structure, or ineffective study habits. 3. Design Workshop: Using the identified gaps, the Academic Skills Coordinator designs a targeted workshop. This includes selecting learning objectives, preparing slide decks, handouts, and practice exercises. Existing materials are revised if gaps are recurring. 4. Deliver Workshop: The Workshop Facilitator presents the workshop to a cohort of students, covering the targeted skills. Interactive exercises and Q&A sessions are included to reinforce learning. Attendance and engagement are recorded. 5. Assess Competency: The system delivers a short quiz or practical exercise aligned with the workshop objectives. Results are automatically scored and compiled into a competency report for each student. 6. Evaluate Effectiveness: The Academic Skills Coordinator compares the competency results to a predefined threshold (e.g., 80% of students achieving proficiency). If the threshold is met, the intervention is deemed successful. If not, gaps remain and remediation is required. 7. Rework Deliverable: When the effectiveness evaluation shows gaps, the Academic Skills Coordinator updates the workshop content, adds supplementary materials, or schedules one-on-one coaching. The revised deliverable is prepared for re-delivery. 8. Archive Outcomes: The system stores the final competency scores, student confidence survey results, and a summary of the intervention. This data is added to the student profile and used for future gap analysis.
