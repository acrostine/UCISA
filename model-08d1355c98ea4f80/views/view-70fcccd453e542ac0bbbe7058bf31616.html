Receive Accreditation Requirements: The Accreditation Officer monitors the accrediting body's communications and receives new or revised accreditation standards. These requirements are logged into the curriculum management system with effective dates and scope details. The officer notifies the Program Director of the incoming requirements. 2. Review Current Curriculum: The Program Director retrieves the current curriculum documentation and maps it against the new accreditation requirements. This step identifies areas of alignment and potential gaps. A preliminary report is generated for the next step. 3. Assess Compliance Gaps: The Faculty Reviewer performs a detailed gap analysis comparing each curriculum element against the accreditation standards. Each gap is documented with severity and impact. The output is a structured gap analysis report. 4. Adjust Curriculum: Based on the gap analysis, the Program Director makes targeted adjustments to course content, learning outcomes, or assessment methods. Changes are documented with rationale and tracked in the system. 5. Validate Changes: The Quality Assurance Manager reviews the adjusted curriculum against the original accreditation requirements. This validation ensures all gaps have been adequately addressed. A validation report is produced. 6. Prepare Submission: The Accreditation Officer gathers all required documentation including the adjusted curriculum, validation report, and supporting evidence. The submission package is formatted according to accrediting body guidelines. 7. Approve Submission: The Quality Assurance Manager conducts a final review of the submission package for completeness and accuracy. Approval signifies readiness for external submission. 8. Submit to Accrediting Body: The Accreditation Officer submits the approved package to the accrediting body via the designated portal or email. A submission confirmation is received and logged in the system. 9. Archive Compliance Documentation: All documentation from the accreditation process is archived in the curriculum management system. This includes requirements, gap analysis, adjustments, validation, and submission records. The archive is indexed for future audits.
