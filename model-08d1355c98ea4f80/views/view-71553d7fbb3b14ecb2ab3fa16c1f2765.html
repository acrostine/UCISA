Module Selection Mgt ()
## Purpose The Module Selection Management process enables students to choose modules that support their academic progression while ensuring all selections comply with programme curricula, academic regulations, and course load balancing requirements. It provides a structured workflow from preference submission through validation, advisor review, and final confirmation. ## Roles - Student: Submits module preferences and revises selections if needed - Academic Advisor: Reviews and approves module selections - System: Validates selections against rules and records confirmed enrolments ## Upstream Inputs - Programme Curricula - Academic Regulations - Student Preferences - Course Load Capacity Data ## Downstream Outputs - Confirmed Module Enrolments - Progression Tracking Records - Course Load Allocation Data ## Key Decisions - Do the selected modules comply with programme curriculum requirements? - Are all prerequisites met for the chosen modules? - Does the course load fall within acceptable limits? - Does the academic advisor approve the selection? ## Exception Paths - If validation fails, the student is prompted to revise selections and resubmit - If the advisor rejects the selection, the student must revise and resubmit for re-review - If course load limits are exceeded, the student must reduce or adjust their selection ## Step Walkthrough 1. Submit Module Preferences: Student submits their preferred module list via the enrolment system. 2. Validate Selections: System checks selections against programme curricula, prerequisites, and course load limits. 3. Revise Selections: Student adjusts their module choices based on validation feedback. 4. Review Selections: Academic advisor examines the validated selections for academic fit and approval. 5. Approve Selections: Advisor formally approves the module selection. 6. Confirm Enrolments: System records the approved selections as confirmed module enrolments. Steps: 1. Submit Module Preferences: The student accesses the module selection system and chooses modules from the available offerings. They submit their preferences, which are captured as a formal request. The system records the submission timestamp and prepares the data for validation. 2. Validate Selections: The system automatically checks each selected module against the programme curriculum to ensure compliance. It verifies prerequisite completion, checks for timetable clashes, and confirms the total course load is within allowed limits. Results are compiled into a validation report. 3. Revise Selections: If validation identifies issues such as missing prerequisites, curriculum mismatches, or overload, the student is notified and must adjust their selections. The student can add, remove, or swap modules. The revised list is resubmitted for re-validation. 4. Review Selections: The academic advisor accesses the student's validated module selections through the advisor dashboard. They review the choices for academic coherence, alignment with the student's goals, and any special considerations. The advisor may add comments or request changes. 5. Approve Selections: The academic advisor makes a final decision to approve or reject the module selections. If approved, the selections move to confirmation. If rejected, the advisor provides reasons and the student must revise. The approval is recorded with a timestamp. 6. Confirm Enrolments: Upon advisor approval, the system finalises the module enrolments. It updates the student's academic record, allocates course load, and triggers notifications to the student and relevant departments. The confirmed enrolment data is stored for progression tracking.
