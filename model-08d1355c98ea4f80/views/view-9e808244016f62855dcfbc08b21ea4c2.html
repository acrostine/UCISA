Receive Transport Request: The process begins when a Transport Requester submits a request for a vehicle. The request includes pickup/drop-off locations, time, and number of passengers. The System logs the request and assigns a unique ID. 2. Assess Vehicle Availability: The Fleet Manager reviews the fleet calendar and current assignments. They check vehicle status (available, in maintenance, or allocated). If no vehicle is available, the request is queued. 3. Allocate Vehicle: The Fleet Manager selects a suitable vehicle and assigns it to the request. The System sends a confirmation to the requester and updates the fleet schedule. 4. Schedule Maintenance: The System automatically generates a maintenance work order when a vehicle reaches a predefined threshold (e.g., 5,000 miles or 6 months). The work order includes inspection checklist and parts needed. 5. Perform Inspection: The Maintenance Technician follows the work order checklist, checking brakes, tires, lights, fluids, and safety equipment. Results are recorded in the system. 6. Review Inspection Results: The Fleet Manager reviews the Inspection Report. If the vehicle passes all checks, it is returned to service. If it fails, the vehicle is flagged for repair or disposal. 7. Initiate Disposal: If the vehicle has major faults or is beyond economical repair, the Fleet Manager creates a disposal request. The request includes vehicle details, condition report, and recommended action. 8. Approve Disposal: The Fleet Manager reviews the disposal request. If approved, the vehicle is marked for disposal and removed from active fleet. If rejected, the vehicle is returned to service with a repair plan. 9. Update Fleet Register: The System records the final status of the vehicle (allocated, in maintenance, disposed, etc.) and generates a Fleet Status Report for management review.
