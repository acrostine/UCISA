## Purpose ICT Service Support provides a structured approach to handling technical assistance requests, incidents, and system alerts across the institution. It ensures that all ICT issues are logged, triaged, investigated, resolved, and closed in a consistent manner, minimising downtime and maintaining service reliability. ## Roles - Service Desk Agent: Logs and triages incoming incidents and service requests - ICT Support Technician: Investigates and resolves technical incidents - ICT Service Manager: Reviews post-resolution findings and approves closure - System: Automated alert ingestion and ticket creation ## Upstream Inputs - User Incident Report - System Alert - Service Request Form ## Downstream Outputs - Resolved Incident Ticket - Root Cause Analysis Report - Service Continuity Update ## Key Decisions - Incident priority and severity classification - Assignment to appropriate support tier - Whether root cause analysis is required - Verification of resolution with the user ## Exception Paths - Incident cannot be resolved within SLA: escalated to senior support - User does not confirm resolution: ticket reopened for further investigation - Root cause identified as systemic: preventive action raised as a change request ## Step Walkthrough 1. Receive and Log Incident: The Service Desk Agent receives an incoming incident via phone, email, portal, or automated system alert. They record all relevant details including user information, description, timestamp, and impact. A unique ticket ID is generated in the ITSM system. 2. Triage and Categorise Incident: The Service Desk Agent evaluates the incident against predefined criteria to determine its priority and severity level. They select the appropriate category (e.g., hardware, software, network) and assign the ticket to the relevant ICT Support Technician or team. 3. Investigate Incident: The ICT Support Technician reviews the ticket details, examines system logs, checks configuration changes, and replicates the issue if possible. They document findings and determine the most effective resolution approach. 4. Resolve Incident: The ICT Support Technician implements the identified solution, which may involve applying a patch, restarting a service, reconfiguring a device, or providing user guidance. They update the ticket with the resolution details and time taken. 5. Verify Resolution with User: The Service Desk Agent contacts the user to verify that the service has been restored and the issue no longer occurs. If the user confirms, the ticket moves to closure. If not, the ticket is reopened for further investigation. 6. Conduct Post-Resolution Review: The ICT Service Manager examines the incident record, resolution steps, and any recurring patterns. They determine if a root cause analysis is warranted and whether a change request or knowledge article should be created to prevent recurrence. 7. Close Ticket: The ICT Service Manager reviews all documentation, confirms that the resolution is complete and verified, and approves the ticket for closure. The ticket is archived in the ITSM system for audit and reporting purposes.
