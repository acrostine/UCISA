## Purpose This process evaluates individual researchers’ contributions, outputs, and development needs using publication records, grant success rates, and peer evaluations. It generates performance appraisals, development plans, and recognition reports to drive talent development, motivate high performance, and align researcher goals with institutional research priorities. ## Roles - Researcher: Provides self-reported data and participates in review - Manager: Reviews data, assesses performance, and determines outcomes - HR Specialist: Finalizes appraisal and archives records - System: Automates data collection and report generation ## Upstream Inputs - Publication Records - Grant Success Data - Peer Evaluation Reports - Researcher Self-Assessment ## Downstream Outputs - Performance Appraisal - Development Plan - Recognition Report - Archived Performance Record ## Key Decisions - Does the researcher meet performance criteria? - What development actions are required? - Is recognition warranted? ## Exception Paths - If performance gaps are identified, a remediation step is triggered before re-evaluation - If the researcher disputes the assessment, an escalation path is available (not detailed here) ## Step Walkthrough 1. Collect Performance Data: The system automatically retrieves publication records from the institutional repository, grant success data from the research management system, and peer evaluation reports from the evaluation platform. This data is compiled into a single dataset for review. 2. Review Compiled Data: The manager reviews the compiled performance data alongside the researcher's self-assessment. They verify completeness, note any discrepancies, and prepare for the formal evaluation. 3. Assess Performance: The manager assesses the researcher's performance against predefined criteria including publication output, grant success rate, and peer evaluation scores. They determine whether the researcher meets, exceeds, or falls below expectations. 4. Address Performance Gaps: If performance gaps are identified, the manager creates a remediation plan outlining specific actions, timelines, and support resources. This step is triggered only when the assessment result indicates below-expectation performance. 5. Re-evaluate Performance: After the remediation period, the manager re-evaluates the researcher's performance using updated data. This step determines if the gaps have been resolved or if further action is needed. 6. Generate Development Plan: Based on the performance assessment (or re-evaluation), the system generates a development plan that includes training recommendations, mentorship opportunities, and career growth milestones. 7. Generate Recognition Report: For researchers who meet or exceed expectations, the system automatically generates a recognition report highlighting achievements, contributions, and recommendations for awards or bonuses. 8. Finalize Appraisal: The HR Specialist reviews the development plan and recognition report, ensures all data is accurate, and finalizes the performance appraisal document. This document is then shared with the researcher and manager. 9. Archive Record: The system stores the final performance appraisal, development plan, and recognition report in the archival database for future reference, compliance, and historical tracking.
