## Purpose Research Dataset Management ensures that all datasets generated during research projects are systematically collected, curated, stored, and preserved. This process enforces data governance and ethical compliance, producing datasets that are well-documented, accessible, and suitable for transparency, reproducibility, and future reuse, thereby enhancing the institution's research credibility and compliance with funder mandates. ## Roles - Data Steward: Oversees curation and compliance checks - Researcher: Provides raw data and metadata - System: Automated validation and storage services - Repository Manager: Manages long-term preservation ## Upstream Inputs - Raw Experimental Data - Metadata Records - Data Governance Policies - Ethical Compliance Guidelines ## Downstream Outputs - Curated Dataset - Dataset Documentation - Preservation Record - Accessible Dataset ## Key Decisions - Does the dataset meet governance and ethical standards? - Is the dataset complete and properly documented? - Should the dataset be preserved for long-term access? ## Exception Paths - If governance validation fails, the dataset is returned to the researcher for correction. - If documentation is incomplete, the dataset is held for rework. - If preservation fails, an alert is sent to the repository manager. ## Step Walkthrough 1. Receive Raw Data: The researcher uploads raw experimental or observational data along with associated metadata to the data management system. This step initiates the dataset management workflow and captures all initial inputs required for curation. 2. Curate Dataset: The data steward reviews the submitted dataset, applies standardised file formats, adds annotations, and ensures metadata completeness. This step prepares the dataset for compliance checking and quality assessment. 3. Validate Governance Compliance: An automated service validates the curated dataset against institutional data governance policies and ethical compliance guidelines. It checks for required consent, anonymisation, and data handling standards. 4. Assess Dataset Quality: The data steward performs a manual review of the dataset to assess completeness, accuracy, and documentation quality. This step determines whether the dataset is ready for storage or requires rework. 5. Store Dataset: The system transfers the approved and quality-checked dataset to the secure institutional repository. The dataset is indexed and assigned a persistent identifier for future access. 6. Preserve Dataset: The repository manager configures preservation actions including backup schedules, format migration plans, and metadata indexing to ensure long-term accessibility and integrity of the dataset. 7. Document Dataset: The data steward creates final documentation including usage notes, citation information, and data dictionary. This documentation supports transparency and reuse by other researchers. 8. Publish Dataset: The system publishes the dataset and its documentation to the repository catalogue, making it discoverable and accessible for internal and external reuse. This step completes the dataset management process. 9. Rework Dataset: The researcher addresses compliance or quality issues identified during validation or assessment. The corrected dataset is resubmitted for re-evaluation.
