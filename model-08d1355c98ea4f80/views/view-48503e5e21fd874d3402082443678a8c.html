Employee Performance Mgt ()
## Purpose This process ensures that every employee receives a structured, fair, and objective performance evaluation that reflects their contributions, identifies areas for growth, and produces a development plan to enhance their effectiveness. It integrates quantitative metrics with qualitative feedback from managers and peers to create a holistic view of performance. ## Roles - HR Manager: Oversees the process, ensures compliance, and approves final evaluations. - Manager: Provides assessment, reviews consolidated evaluation, and approves development plan. - Employee: Receives evaluation, participates in feedback collection, and reviews development plan. - System: Automates data collection, notification, and record-keeping. ## Upstream Inputs - Performance Metrics: Quantitative data on employee output, quality, and timeliness. - Manager Assessments: Qualitative evaluations from direct supervisors. - Peer Reviews: Feedback from colleagues on collaboration and teamwork. - Job Objectives: Pre-defined goals and key results for the review period. ## Downstream Outputs - Performance Evaluation: Final documented assessment of employee performance. - Development Plan: Actionable plan for skill improvement and career growth. - Updated Employee Record: Performance data archived in HR system. ## Key Decisions - Does the consolidated evaluation meet the expected performance threshold? - Does the development plan adequately address identified gaps? - Should the evaluation be escalated for HR review due to discrepancies? ## Exception Paths - If performance metrics are incomplete, the process loops back to collect additional data. - If the manager assessment and peer reviews conflict significantly, the evaluation is escalated to HR Manager for resolution. - If the employee rejects the development plan, it is sent back for revision. ## Step Walkthrough 1. Collect Input Data: The system gathers performance metrics, manager assessments, peer reviews, and job objectives from various sources. 2. Consolidate Feedback: The system aggregates all collected data into a preliminary evaluation draft. 3. Review Preliminary Evaluation: The manager reviews the draft and determines if it is complete and accurate. 4. Assess Against Objectives: The manager compares the evaluation against job objectives to identify gaps and strengths. 5. Create Development Plan: Based on the assessment, a development plan is drafted to address skill gaps and career goals. 6. Approve Development Plan: The manager reviews and approves the development plan. 7. Finalize Evaluation: The system finalizes the performance evaluation and updates the employee record. 8. Notify Employee: The system sends the final evaluation and development plan to the employee for review. Steps: 1. Collect Input Data: The system automatically retrieves performance metrics from the HR dashboard, manager assessments from the manager portal, peer reviews from the feedback system, and job objectives from the goal management module. All data is timestamped and logged for audit purposes. 2. Consolidate Feedback: The system merges quantitative metrics with qualitative feedback, normalizing scores and comments. It flags any missing or conflicting data for manual review. A preliminary evaluation document is generated. 3. Review Preliminary Evaluation: The manager accesses the preliminary evaluation through the manager portal. They check that all required data is present and that the feedback is consistent. If issues are found, they can request additional data collection. 4. Assess Against Objectives: The manager reviews each objective and assesses whether the employee met, exceeded, or fell short of expectations. They document specific examples and assign a performance rating. This step determines the overall performance level. 5. Create Development Plan: Using the performance assessment, the system generates a draft development plan that includes recommended training, mentoring, and stretch assignments. The manager can customize the plan to address specific gaps and career aspirations. 6. Approve Development Plan: The manager reviews the draft development plan and either approves it or sends it back for revision. Approval triggers the finalization of the evaluation. 7. Finalize Evaluation: The system combines the performance assessment and approved development plan into a final evaluation document. It updates the employee record with the new rating and plan, and archives the data for future reference. 8. Notify Employee: The system generates a notification email with a link to the final evaluation and development plan. The employee can log in to view, acknowledge, and provide feedback on the documents.
